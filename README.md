# 🛍️ Витрина данных и Ad-hoc аналитика E-commerce

> Проект по разработке витрины данных маркетплейса и решению ad hoc-задач для бизнес-аналитики

---

## 🎯 О проекте

В рамках проекта была разработана витрина данных для маркетплейса **«ВсёТут»**, которая агрегирует поведенческие характеристики клиентов. На основе витрины решены 4 ad hoc-задачи для бизнес-анализа.

### Ключевые бизнес-вопросы, которые решает проект:

- **Кто наши клиенты?** — сегментация по количеству заказов
- **Кто приносит наибольшую прибыль?** — ранжирование по среднему чеку
- **Как работают разные регионы?** — сравнение метрик по регионам
- **Как меняется активность по месяцам?** — когортный анализ

## 🏪 Витрина данных

### Цель витрины

Собрать агрегированные характеристики поведения пользователей на основе их заказов для последующего анализа.

### Фильтрация данных

- ✅ Только заказы со статусами **«Доставлено»** и **«Отменено»**
- ✅ Только 3 региона с наибольшим количеством заказов

### Структура витрины `product_user_features`

| Группа | Поле | Описание |
|--------|------|----------|
| **Базовая информация** | `user_id` | Уникальный идентификатор клиента |
| | `region` | Регион покупки |
| | `first_order_ts` | Дата первого заказа |
| | `last_order_ts` | Дата последнего заказа |
| | `lifetime` | Жизненный цикл клиента (дни) |
| **Информация о заказах** | `total_orders` | Общее количество заказов |
| | `avg_order_rating` | Средняя оценка заказов |
| | `num_orders_with_rating` | Количество заказов с оценкой |
| | `num_canceled_orders` | Количество отмененных заказов |
| | `canceled_orders_ratio` | Доля отмененных заказов |
| **Информация о платежах** | `total_order_costs` | Суммарная стоимость заказов |
| | `avg_order_cost` | Средняя стоимость заказа |
| | `num_installment_orders` | Количество заказов в рассрочку |
| | `num_orders_with_promo` | Количество заказов с промокодом |
| **Бинарные признаки** | `used_money_transfer` | Использовал ли денежный перевод |
| | `used_installments` | Использовал ли рассрочку |
| | `used_cancel` | Отменял ли хотя бы один заказ |
